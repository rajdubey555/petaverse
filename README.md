# 🐾 PetVerse — Full-Stack Pet Care & Adoption Marketplace

PetVerse is a modern, enterprise-grade full-stack web application designed for pet adoption, rehoming, community reviews, and real-time administrative content moderation.

---

## ✨ Key Features

- 🐶 **Multi-Species Marketplace**: Browse & list pets across 8 distinct categories (Dogs, Cats, Birds, Fish, Rabbits, Hamsters, Reptiles, Others).
- 📞 **Direct Contact Actions**: Quick-connect buttons (*Call Now* & *Send Email*) with direct phone/email integration.
- 🛡️ **Enterprise Admin Moderation**: Real-time stats dashboard, 1-click user suspension, pet featured status toggle, and report resolution.
- 🔐 **Secure Authentication**: JWT Access & Refresh token rotation, bcrypt password hashing, and Google OAuth 2.0 integration.
- 🎨 **Modern Aesthetics**: Glassmorphism UI, light/dark mode support, Framer Motion animations, and edge-to-edge responsive layout.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite, Redux Toolkit, TailwindCSS, Framer Motion
- **Backend**: Node.js, Express.js (REST API Architecture)
- **Database**: MongoDB Atlas Cloud
- **Storage**: Cloudinary Cloud Media Storage
